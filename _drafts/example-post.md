## Publishing a post

1. Create `_posts/YYYY-MM-DD-my-post-name.md` with the same front matter as this file.
2. Write in Markdown. Push to GitHub and the post goes live at `/blog/my-post-name/`.
3. Keep unfinished posts in `_drafts/` (no date in the file name).
