Backend Developer, A5 SYNC

Feb 2025 – present · US (remote) · full-time

An eCommerce platform where companies sell products sourced from many vendors. I build its backend.

  • The catalog holds millions of products from several vendors, and every company's data has to stay separate. I built the multi-tenant backend behind listing, quoting, orders and fulfillment.
  • Product data comes from three vendor FTP servers. I wrote the pipelines that fetch it, parse it, check it and sync millions of SKUs, so the catalog stays accurate.
  • Companies can sign up and manage their own catalogs, listings, orders and quotes without our help.
  • Built an API Builder. Each reseller can create and publish their own data APIs just by configuring them, with no code. Every API checks its results before returning them, so outside users get consistent data.
  • Built a warehouse management system that tracks every item in stock: receiving, putaway, order picking and stock reservations. Inventory and locations can be bulk-imported from Excel.
  • Built subscriptions and recurring billing. A recurring quote turns into a subscription, and each renewal is generated on schedule with no manual work.
  • Built an organization merge that combines duplicate customer accounts and safely moves their quotes, orders, payments and pricing. It runs as a background job and emails the account owners a summary.
  • The services are written in Node.js and TypeScript. They use PostgreSQL, Redis for caching and RabbitMQ for background events.
  • Search runs on Elasticsearch, so a typo still finds the product. I also built the filters and tuned the ranking.
  • I also integrated a payment gateway, set up a two-way sync with HubSpot, and added product listing to Amazon Seller Central through its API.

Node.js, TypeScript, Express, PostgreSQL, Redis, RabbitMQ, Elasticsearch

Backend Developer, Varicon

Nov 2022 – May 2026 · Australia (remote) · part-time

Software for construction companies: billing, timesheets, payroll and supplier invoices. I worked on the backend part-time for three and a half years.

  • Moved the app from one customer per deployment to multi-tenant. That meant keeping each customer's data separate, adding role-based access, and adding JWT login with two-factor.
  • Built the supplier merge, which changes data in several services and databases at once. It uses the Saga pattern: each step is tracked, and if one fails the earlier steps are undone.
  • Moved billing, timesheets and third-party integrations onto AWS SQS, so each can slow down or fail without taking the main app with it.
  • Set up a primary and replica database with load balancing, so the app stays quick when traffic is high.
  • Built invoice OCR that learns. When a user corrects a supplier match, the correction is stored as an embedding and used to suggest the right supplier next time.
  • Built document search: semantic search over a vector database, image similarity, and LLM summaries and questions over uploaded files. I also built Spotlight, a search box where you describe what you want to do and it finds the feature.
  • Built PDF export for large reports on AWS Lambda. It runs in the background and streams progress to the user over WebSockets. I also added real-time notifications on web (WebSockets) and mobile (Firebase Cloud Messaging).
  • Automated payroll with Python and Pandas. It reads Google Sheets and produces files ready to import into Xero and MYOB. I also integrated MYOB, Xero and EzzyBills OCR for invoices and bills.
  • Set up testing: Selenium with Behave for UI tests, Locust for load tests and Django Silk for query profiling. APIs shipped with automated tests and CI/CD.

Python, Django, PostgreSQL, Pandas, AWS (Lambda, SQS), WebSockets, vector databases
